Rosters

Rosters, injury tags, season stats and each team’s points allowed load live from ESPN’s public data each time you pick a team, then stay cached on this device for a few hours (use Refresh rosters to pull them again). Early in a season, a player’s ratings blend his few current-season games with last season. Players listed Out, Doubtful, on injured reserve or the practice squad sit automatically; untick anyone else you want to sit. The starting quarterback is whoever has thrown the most this season; untick him to start the backup. Overtime follows the current regular-season rules, so a game can end in a tie. Results are random, so every game plays out differently.
